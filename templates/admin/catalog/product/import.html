How photos work

  • Put photo file names in the images column (shown for every color) and, on a variant row, in color_images (that color only).
  • Separate photos with a comma or |, for example tee-1.jpg, tee-2.jpg. A file name or a full http(s) link both work, and you can mix them.
  • Photos only? Leave the CSV empty, choose just the photo ZIP(s) and click the button: the photos are attached to the products whose CSV row listed those file names.
  • Photos can come now or later. File names found in the Photos ZIP below are attached now (you can choose several ZIP parts at once: up to {{ max_zips }} ZIPs, {{ max_zip_mb }} MB each, {{ max_total_mb }} MB together). File names that are not in the ZIP, or when you upload no ZIP, are saved with the product and the photos are attached automatically when you upload them later with Upload photos.
  • Each photo can be JPEG, PNG or WebP, up to 5 MB, and is compressed automatically.
  • Maximum {{ max_per_product }} photos per product (shared plus per-color), {{ max_refs }} photos and {{ max_links }} links per import. Import in batches if you have more.
  • Photos listed in the CSV replace that product's existing photos of the same kind, so importing the CSV again never creates duplicates. Photos are added in the background after the products are saved.
